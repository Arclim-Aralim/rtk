# Коммерческая экосистема Ростелеком

Прототип по ТЗ «РТК Хакатон 2026»: радар присутствия, инвестиционный навигатор и калькулятор сделок. Белый интерфейс, корпоративная палитра #7700FF / #FF4F12 / #101828, предоставленный горизонтальный логотип. Arial разрешён как запасной шрифт; RostelekomBasis в исходных материалах отсутствует.

## Стек и сервисы

- `frontend/`: React, JavaScript (JSX), Tailwind CSS 4, Vite, Leaflet. Установка через pnpm; версии зафиксированы в `pnpm-lock.yaml`.
- `services/gateway/`: ASP.NET Core / C# / .NET 10. Вход с паролем и TOTP, ограничение попыток, HttpOnly/SameSite сессии, защита изменяющих запросов, подписки и уведомления, шлюз к Python. Отдаёт собранный фронтенд.
- `services/analytics/`: Python / FastAPI. SQLite, фильтры, карта компаний и проектов, поиск ниш, расчёт цены по аналогам, проверка CSV, CSV/CRM и Word экспорт.

Python API слушает только `127.0.0.1:8091`. Единственная внешняя точка входа — C# на порту 8080. Данные сервисов независимы: `data/analytics/analytics.sqlite3`, `data/gateway/user.json` и `subscriptions.json`. Демонстрационный прототип рассчитан на одну учётную запись аналитика, создаваемую при первом запуске. Сессии находятся в памяти и завершаются при перезапуске шлюза.

## Возможности

- Карта с масштабированием, плотностью по выручке, выбором компании и фильтрами по региону, отрасли, выручке, росту и статусу клиента. Выбор зоны на карте: два угла прямоугольника; статистика, список и экспорт учитывают выделение.
- Рейтинг ниш: доля потенциальных клиентов × положительная динамика × логарифм совокупной выручки. Формула показана в интерфейсе.
- Проекты с фильтрами по стадии, инициатору через поиск, локации, отрасли, потребности. Таймлайн связан с картой; проект переносится в калькулятор.
- Подписки на новые проекты с уведомлениями внутри приложения каждые 60 секунд. Email/SMS не настроены. Существующие проекты при создании подписки не считаются новыми.
- Цена по пяти ближайшим аналогам с весами по масштабу, сроку и региону. Региональные, срочные, финансовые и уникальные коэффициенты. Нижняя граница от себестоимости / 0,9, оптимум от себестоимости / 0,75. Цены без НДС. Это объяснимая эвристика прототипа, а не обученная оценочная модель.
- CSV/CRM экспорт компаний, проектов, истории и расчёта; DOCX предложение и Word-совместимый HTML в `.doc` (не бинарный Word 97).
- Атомарный импорт UTF-8 CSV до 5 МБ / 10 000 строк, шаблоны, проверка значений, обновление по устойчивому идентификатору, происхождение записей, защита формул CSV.
- TOTP с первичным подключением аутентификатора, проверкой повторного использования кода, лимитами попыток и восьмичасовой сессией.

## Данные и ограничения

Начальный набор **синтетический**: 48 компаний, 16 проектов, 40 исторических сделок в четырёх регионах. Записи содержат `demo`, `source`, `sourceUrl`, `updatedAt`. Показатели не являются реальными данными ФНС, ЕИС или инвестиционных реестров. Реальные источники подключаются через проверенные CSV-выгрузки; прямого парсинга государственных ресурсов и live-парсинга цен нет. Если для типа проекта импортированы реальные сделки, демонстрационные аналоги исключаются из расчёта.

Для карты используется общедоступная подложка OpenStreetMap с атрибуцией. При недоступности тайлов показывается сообщение; точки и масштабирование остаются доступны. Для промышленной нагрузки нужен собственный/договорной поставщик тайлов.

## Локальная разработка

Требуются Node.js 22.12+ и pnpm, .NET SDK 10, Python 3.12+.

```bash
cd frontend
pnpm install
pnpm dev
```

```bash
cd services/analytics
python -m venv .venv
.venv/bin/pip install -r requirements.lock
DATA_DIR=./data .venv/bin/python -m uvicorn main:app --host 127.0.0.1 --port 8091
```

```bash
cd services/gateway
ADMIN_USER=admin ADMIN_PASSWORD='<случайный пароль от 12 символов>' ASPNETCORE_URLS=http://127.0.0.1:5080 dotnet run
```

Фронтенд Vite перенаправляет `/api` на 5080. Для PowerShell задайте переменные через `$env:ИМЯ='значение'`; Python расположен в `.venv/Scripts/`.

```bash
cd frontend && pnpm build
cd ../services/gateway
dotnet publish -c Release -r linux-x64 --self-contained true -o ../../runtime/gateway
cp -r ../../frontend/dist ../../runtime/gateway/wwwroot
```

## Запуск на указанном сервере

Каталог: `/home/vboxuser/rostelekom`. Собранный self-contained .NET сервис расположен в `runtime/gateway/`; отдельный системный .NET не нужен. Python-окружение создаётся через uv в `.venv/` с использованием системного Python 3.14. Для повторного развёртывания: `tools/uv-x86_64-unknown-linux-gnu/uv venv --python /usr/bin/python3 .venv`, затем `tools/uv-x86_64-unknown-linux-gnu/uv pip install --python .venv/bin/python -r services/analytics/requirements.lock`. Системные пакеты и чужие проекты не меняются.

```bash
cd /home/vboxuser/rostelekom
bash scripts/start.sh
bash scripts/status.sh
bash scripts/stop.sh
```

Адрес: `http://192.168.3.9:8080`. При первом запуске `scripts/start.sh` создаёт случайный пароль в `.env` с доступом только владельцу. Имя — `admin`. Посмотреть начальные реквизиты: `cat /home/vboxuser/rostelekom/.env`. При первом входе пользователь добавляет показанный TOTP-ключ в приложение-аутентификатор и подтверждает кодом.

Запуск через nohup сохраняет процессы после закрытия SSH; автоматический старт после перезагрузки ОС не настроен. Логи — `logs/`. Для внешней эксплуатации нужны HTTPS на reverse proxy и многопользовательская модель ролей. LAN-демонстрация использует HTTP, поэтому передавать реальные рабочие пароли и данные через неё не следует.

Пароль из `.env` используется только при создании `user.json`. Его последующее изменение не меняет хеш существующей учётной записи. Резервируйте `data/` и `.env`; для сброса TOTP остановите сервис и восстановите резервную копию или выполните контролируемый сброс `TotpEnabled` в `user.json` с серверным доступом владельца. Ключ TOTP хранится в файле владельца, шифрование ключа внешним хранилищем секретов не настроено.

## Проверки

```bash
cd frontend && pnpm build
cd ../services/gateway && dotnet build
cd ../analytics
python -m pip install httpx
python -m unittest -v
```

Тесты используют отдельную временную БД. Проверяются фильтры и агрегаты, границы и монотонность цены, DOC/DOCX/CSV, атомарность и идемпотентность импорта, защита формул CSV, приоритет реальных сделок. Сквозная проверка шлюза: `python scripts/smoke_gateway.py http://127.0.0.1:5080` с тестовыми `QA_USER` и `QA_PASSWORD`. Она предназначена для изолированной тестовой учётной записи и подключает её TOTP.


Также подготовлен compose.yaml для альтернативного развёртывания через Docker Compose. Этот вариант на сервере не запускался: используется автономный запуск под vboxuser без sudo.


## Обновление: исходная фактура, ФНС и площадки деятельности

Загруженная фактура содержит 759 клиентских ИНН, 63 проекта и 20 позиций оборудования. Она не содержит выручку, динамику выручки, точные координаты и подтверждённые фактические офисы. Эти значения остаются null. Стадии проектов не выведены из одного года ввода, год сохраняется без выдуманной даты; потребность «ИТ-инфраструктура» помечена как предположение.

В разделе «Данные и источники» добавлен импорт XLSX/CSV исходного формата ФНС и списка клиентов, а также всего Excel фактуры. ФНС-выгрузка требует явной даты среза. Поддерживается до 25 МБ и 50 000 строк за импорт; большие выгрузки нужно разбивать. Полная онлайн-выгрузка Ростовской области автоматически не загружена: портал вернул выборку 465 627 записей, но браузерная загрузка Excel не завершилась. Демо и реальные данные можно переключать отдельно; по умолчанию показываются реальные.

Совпадение с клиентской базой проверяется по строковому ИНН с сохранением ведущих нулей. Отсутствие ИНН в загруженном списке означает «Не найден в загруженной клиентской базе», а не доказательство отсутствия договора вообще. ФНС МСП не покрывает весь крупный бизнес. Членство в МСП (present/excluded/unknown) и состояние деятельности (active/terminated/unknown) хранятся отдельно. Исключение из МСП не закрывает организацию. Статус прекращения требует отдельного источника ЕГРЮЛ/ЕГРИП; старые срезы ФНС не перетирают новые, а неизвестный статус не отменяет подтверждённое прекращение.

Для одного ИНН доступны несколько площадок. CSV площадок содержит `inn,region,locality,address,source,sourceUrl,observedAt,status,lat,lon,geoAccuracy`. Статусы: candidate, confirmed, rejected. Подтверждённый статус устанавливается оператором по источнику, автоматически по совпадению названия адрес не подтверждается. Шаблон скачивается в приложении. Координаты необязательны; без них объект остаётся в таблице, а не переносится в центр области. География фильтруется отдельно по регистрации, деятельности или обоим видам. Есть фильтры расхождений региона и населённого пункта. Неподтверждённые площадки исключены из основной геоаналитики.

В калькуляторе появился подбор оборудования по фактуре. Принятая явная формула: оборудование = Σ(количество × базовая цена); работы = Σ(количество × цена × коэффициент сложности) × сумма ставок выбранных работ × коэффициент уровня. Региональный коэффициент применяется к работам в основном расчёте. Для южных регионов при загруженной фактуре используется 1,1 из таблицы. Базовые цены не выдаются за актуальные рыночные, история аналогичных сделок по-прежнему демонстрационная, пока не импортированы реальные сделки.

Проверки: 12 тестов аналитики и реестров, сборки React и C#. Отдельно проверена загрузка предоставленной фактуры в изолированную БД. Команда загрузки на сервере: `.venv/bin/python scripts/import_facts.py imports/Хакатон_2026_фактура.xlsx`. Файл клиента не размещается в публичной директории фронтенда.

Координаты: при импорте клиентов и проектов применяется локальный справочник GeoNames (CC BY 4.0), только Ростовская область. Центр населённого пункта или точка района помечаются как приблизительные и не подтверждают адрес офиса. Неоднозначные совпадения остаются без координат. Сборка справочника: scripts/build_gazetteer.py; обновление существующих записей: scripts/geocode_existing.py. Источник: https://download.geonames.org/export/dump/


Стили интерфейса полностью используют Tailwind CSS 4. В src/ui.js находятся переиспользуемые наборы утилит и responsive/state-варианты, включая оформление Leaflet; семантические имена служат только selector hooks, собственных CSS-правил нет. src/styles.css содержит только импорт Tailwind и @theme. Диаграммы используют SVG-атрибуты размеров. Лицензия Leaflet сохранена в public/leaflet-license.txt.
